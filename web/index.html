HOW THE LIBRARY IS USED

In Mod Creator mode, a source that has a saved whitelist contributes only its ticked faces; a source with none behaves exactly as before (all faces pooled). Globally-blacklisted NPCs (right) are removed from every source. The library lives on this PC only and is reused across modlists. Library build (header) packs the curated faces into self-contained plugins.

3 · Curated mods → library plugin

Tick the curated mods for the library set (blacklist applied). Every face becomes a donor NPC with its FaceGen, head parts, custom race and skin copied in, so the set needs no source mods and travels between MO2 instances. The build packs faces by mod into as many ESPFE plugins as the 2048-record limit needs (FDA_Library_1.esp, _2…), each with its own BSAs, in one mod folder. IDs are stable: rebuilding after curating more faces appends, so existing SkyPatcher configs keep working.

4 · Build

The set lands under the output root as <name>/ (one mod folder: all plugins + BSAs + READMEs); the map (yaml + csv) of donor ↔ original face is written next to it and under library/builds/. In Mod Creator the whole set is one source under “Library builds” and feeds SkyPatcher configs (copyVisualStyle=<plugin>|<donor>); a config's README names the plugins it actually uses.
