HOW THE LIBRARY IS USED

In Mod Creator mode, a source that has a saved whitelist contributes only its ticked faces; a source with none behaves exactly as before (all faces pooled). Globally-blacklisted NPCs (right) are removed from every source. The library lives on this PC only and is reused across modlists.
